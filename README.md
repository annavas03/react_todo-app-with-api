
# React Todo App with API

A task management application built with React and TypeScript. It allows users to manage their todos, track completed tasks, and edit task titles. The application interacts with an API to store and update todos.
DEMO(https://annavas03.github.io/react_todo-app-with-api/)

## Technologies Used

- React
- TypeScript
- React Redux
- REST API
- SCSS
- Bulma
- Classnames

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone <your-repository-link>
   ```

2. Navigate to the project directory:

   ```bash
   cd react_todo-app-with-api
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open the application in your browser at the URL provided in the terminal.

## Features

- **Add Todos** – Create new tasks.
- **Delete Todos** – Remove tasks from the list.
- **Toggle Todo Status** – Mark individual tasks as completed or active.
- **Toggle All** – Change the status of all todos at once.
- **Edit Todo Titles** – Rename tasks by double-clicking their titles.
- **Keyboard Support** – Save changes with Enter or cancel editing with Escape.
- **API Integration** – Synchronize todo data with the backend.
- **Loading Indicators** – Display loaders while waiting for API responses.
- **Error Notifications** – Show error messages when API requests fail.
- **Responsive Design** – Adapt the interface to different screen sizes.
